# Doações CSV – TP3

Leitura e escrita dos arquivos CSV do Sistema de Gestão de Doação de Equipamentos Eletrônicos.

- Java 17 ou mais novo, sem dependências externas.
- No IntelliJ: File > Open > pasta `doacoes-csv`, marque `src` como Sources Root e rode `br.infnet.doacoes.Main`.
- Os arquivos ficam em `dados/` (separador `;`, UTF-8).
